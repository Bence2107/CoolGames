# 🎮 CoolGames

### This project was created as part of a university project. The goal was to develop a simple online game store using PHP and MariaDB, where users can purchase games using a unique virtual currency called **CatCredit**.  
The main motivation behind the project was to get familiar with web applications and to learn the PHP programming language.

> ### ⚠️ The project was made public after its completion.

---

## ⚙️ Features

- User registration and login  
- Game purchasing  
- Profile customization  
- Game rating system  

---

## 🛠️ Technologies

- PHP (server-side logic)  
- MariaDB (database)  
- HTML, CSS, JavaScript (front-end)

---

## 🚀 Installation

> ⚠️ This application is specifically designed to run using [XAMPP](https://www.apachefriends.org/index.html) and its PHPMyAdmin interface. XAMPP is required for proper usage.

1. Clone the repository:  
   `git clone https://github.com/Bence2107/CoolGames`  
   (or download via GitHub → Code → Download ZIP)

2. Copy the contents of the project to the **xampp/htdocs** folder

3. Launch the XAMPP application and start the **Apache** and **MySQL** modules with the **default settings**

4. In your browser, go to:  
   `localhost`  
   The site should now be up and running
