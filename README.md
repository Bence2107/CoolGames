# 🎮 CoolGames

### Ez a projekt egy egyetemi beadandó keretében készült. A cél egy egyszerű webes webáruház létrehozása volt PHP és MariaDB segítségével, ahol a felhasználók különböző játékokat vásárolhatnak meg egy különleges, **MacskaKredit** segítségével. Főbb motiváció a webes alkalmazásokkal való ismerkedés és a PhP programnyelv elsajátítása.

> ### ⚠️ A projekt utólag kerűlt publikálásra

---

## ⚙️ Funkciók

- Felhasználói regisztráció és bejelentkezés
- Játék vásárlása
- Profil testreszabása
- Játékok értékelése 
---

## 🛠️ Technológiák

- PHP (szerveroldali logika)
- MariaDB (adatbázis)
- HTML, CSS, JavaScript (front-end)

---

## 🚀 Telepítés

> ⚠️ Az alkalmazás kifejezetten a [XAMPP](https://www.apachefriends.org/hu/index.html) PHPMyAdmin alkalmazását használja. Ez szükséges a projekt futtatásához.

1. Klónozd a repót: `git clone https://github.com/Bence2107/CoolGames` (vagy töltsd le: GitHubon Code -> Download ZIP

2. Másold be a projekt tartamát a **xampp/htdocs** mappába

3. Indítsd el a XAMPP Appot, és indítsd el az **Apache** és **MySQL** modulokat **alap beállításokkal**!

4. Böngészőben: `localhost`, és az oldal használatra kész
